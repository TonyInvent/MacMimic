# SpacemiT K3 COM260

The K3 runtime uses Bianbu riscv64 and the system CPU ONNX Runtime. The V02 board at the lab ran Bianbu 4.0.4, kernel 6.18.3-generic and ONNX Runtime 1.23.2. Run these commands from the repository root.

| K3 native interface | Robot harness |
| --- | --- |
| can0 | Former kcan1 |
| can1 | Former kcan2 |
| can2 | Former kcan3 |
| can3 | Former kcan4 |
| can4 | OpenIMU, former spriteimu0 |

The K3 profile remaps the interface column of the verified motor table. Joint order, calibration, gains and limits still come from the reviewed OpenSprite files. The controller matches individual FlexCAN driver echoes from its sending socket by order, CAN ID and payload. The audit bounds completion using monotonic echo receipt and checks the 20 ms limit. RX age uses the kernel software timestamp. A powered run requires matching disabled and injected-fault evidence for its mode, board configuration and runtime binaries.

## Build and replay

```bash
sudo apt-get update
sudo apt-get install cmake g++ make libonnxruntime-dev python3-numpy
bash sim2real/build-k3.sh
```

On the lab board all 15 native tests passed. The 803-frame walking replay compared every raw action and joint target against the Jetson reference. Maximum absolute errors were 0.00000167 and 0.00000042 respectively. Standing Groove passed both 600-frame comparisons and Disco Point passed both 1,640-frame comparisons. These tests use recorded observations.

## Hardware commissioning

With the robot supported and drives disabled, configure the five Native CAN FD ports at 1 Mbit/s arbitration and 5 Mbit/s data. The launcher expects an Xbox controller at `/dev/input/js0`. Run the desired mode with `--qualify` to collect its own disabled full-length and deadline-fault records.

```bash
sudo env PYTHONPATH="$PWD/runtime/src" python3 runtime/tools/k3_board.py --up
bash scripts/k3-run.sh xbox --qualify
bash scripts/k3-run.sh standing-groove --qualify
bash scripts/k3-run.sh disco-point --qualify
```

Use `--replay` for a file-only run of any mode. Once its qualification passes, use `--powered` at the operator terminal with sling support and the cutoff within reach. The confirmations are `XBOX300`, `GROOVE12` and `DISCO1640`. Hold LB and RB for three seconds to request disable. K3 hardware qualification and powered motion are pending.
